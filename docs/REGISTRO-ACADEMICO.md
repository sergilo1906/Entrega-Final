# Registro académico

La reconstrucción, simplificación, correcciones, pruebas y documentación han contado con asistencia de Codex/IA. No se declara autoría exclusivamente manual. Git y las pruebas acreditan cambios técnicos, no horas efectivas ni comprensión del alumno. Las normas y rúbrica exacta del centro deben contrastarse con el profesor.

| Horas efectivas del alumno | PENDIENTE; no deducir de prompts, esperas o logs |
| Revisión y comprensión del código | PENDIENTE DE REVISIÓN PERSONAL |
| Recorrido personal con cliente/admin | PENDIENTE; las pruebas automáticas no lo sustituyen |
| Reglas del centro sobre asistencia de IA | PENDIENTE DE CONTRASTAR CON EL PROFESOR |

La reducción de alcance se realiza por petición expresa: se retiran funcionalidades avanzadas antes existentes, no se presentan como si nunca hubieran existido. [Trazabilidad](ANEXO-TRAZABILIDAD.md) conserva referencias a la versión histórica en Git. Se mantienen declaraciones académicas y procedencia; los inventarios técnicos obsoletos pueden consultarse en esos commits.

Herramientas utilizadas: Git/GitHub, Node/npm, Astro/TypeScript/Tailwind, Firebase Emulator Suite, Vitest, Node Test Runner y Playwright. [Pruebas actuales](PRUEBAS.md) y [matriz](MATRIZ-REQUISITOS.md) describen el alcance verificable. No constituyen una certificación productiva ni una nota académica.

Antes de entregar, practicar la defensa y completar únicamente información comprobable. No se envía nada al profesor automáticamente.



La publicación Entrega-Final añade una muestra ficticia catalana y un historial Git inicial limpio. No elimina la procedencia del trabajo anterior ni la declaración de asistencia. Los datos de muestra no acreditan una barbería real ni clientes reales. Las credenciales de WEB se entregan al propietario fuera del repositorio público.
